# Backend - Node.js & Express.js

This is the backend for my project, built using **Node.js** and **Express.js**. It serves data to the frontend and performs CRUD operations on a **MySQL** database hosted on **Railway**.

## 🚀 Technologies Used

- **Node.js** - Server-side runtime
- **Express.js** - Backend framework
- **MySQL** - Database (Hosted on Railway)
- **fs** - Handling file operations
- **cors** - Enabling CORS for frontend communication
- **dotenv** - Managing environment variables

## 📂 Git Branches

The project has two branches:

- **jsonModel** - Fetches data from a JSON file.
- **sqlModel** - Fetches and manipulates data using MySQL.

Switch between branches to explore the difference between fetching from a JSON file and using a MySQL database.

## 📌 Key Learnings

- Integrating **MySQL** with **Node.js & Express.js**.
- Handling **CRUD** operations in a real-world project.
- Deploying a **MySQL database** on **Railway**.
- Seamlessly switching between **Git branches** while developing.
- Implementing **charts** and handling data efficiently.

## 💡 Challenges Faced

- **Hosting MySQL on Railway** for the first time.
- Connecting MySQL with **Node.js & Express.js**.
- Ensuring smooth data fetching and API responses.
